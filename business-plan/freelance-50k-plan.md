# 最初の有料顧客1人を取るための計画

今のゴールは「月5万円」でも「営業件数」でもなく、**最初の1人に、納得してお金を払ってもらうこと**。件数を追うのはそのあとでいい。押し売りはしない前提で組んでいます。

---

## あなたが売っているもの（再定義）

**売っているのは「フォーム制作」ではなく、「予約・問い合わせ・顧客管理まわりの面倒を聞き取って、その人が回せる形に整理すること」。** Tally・Google Workspace・Notion・AIは、その整理を実現するための手段であって、商品そのものではない。会話の中でも「フォームを作ります」ではなく「今バラバラになっている作業を整理します」という言い方で通す。

### なぜあなたに頼むメリットがあるのか（差別化の核）

これは売り文句ではなく、会話の端々で自然ににじませるための"自分の中の軸"として持っておく。

- ヨガを長く学び、教える側の経験もある → レッスンやセッションに集中したい一方で、予約・問い合わせ・顧客管理のような裏方業務に時間を取られる感覚を、外から聞いた話ではなく実感として知っている。
- 営業事務・営業サポートの実務経験が長い → 「なんとなく整理したい」ではなく、実際に回る事務フローが分かる。
- Tally・Google Workspace・Notion・AIを組み合わせて仕組み化できる → 現場感覚と実務の両方を、ITが苦手な人でも使える形に翻訳できる。

**使い方の注意**：ヨガ哲学やスピリチュアルな話を売り文句にしない。使うのは「現場を知っている」という一点だけ。会話では「私も教える側なので分かるんですが」くらいの軽さで十分で、資格や学びの話を長く語る必要はない。

## 最初の1件を取るまでの流れ

### 1. 最初に声をかけるべき人の条件

数を絞る。全員に送らない。次の条件に当てはまる人を**3〜5人**だけ思い浮かべる。

- ヨガ講師・セラピスト・個人サロンなど、体を使う仕事をしている
- すでにある程度お客さんがいて、予約や問い合わせをLINE・Instagram DM・電話などで**手作業で**さばいている（＝困りごとが実在する。暇な人はまだ困っていない）
- 面識があり、雑談として連絡しても不自然でない関係（赤の他人へのコールドDMは今回は保留。最初の1件は"顔が見える相手"から取る）

この3〜5人以外には今は連絡しない。

### 2. 最初の会話（売り込まない）

いきなり営業しない。近況を聞く延長で自然に始める。

```
〇〇さん、お久しぶりです！最近レッスン（セッション）どうですか？
```

雑談の中で相手が忙しさや大変さに触れたら、そこで初めて仕事の話を混ぜる。

```
実は最近、ヨガ講師さんとかセラピストさんの予約・問い合わせまわりを
整理するお手伝いを始めてて。〇〇さんのところって、今そのへんどうしてるんですか？
```

「お手伝いしています、いかがですか」で止める。ここで価格や商品名は出さない。

### 3. 困りごとの聞き方

分析的に質問攻めにしない。相手が話したことを広げるだけでいい。

- 「今、予約とか問い合わせって、どうやって受けてます？」
- 「それ、地味に手間じゃないですか？」（共感で深掘り。詰問しない）
- 「一番面倒だなって思うのはどの部分ですか？」

ここで具体的な業務（LINEで一件ずつ確認している／予約が重複する／お客さんの情報がバラバラ、など）が出てきたら、それが提案の材料になる。無理に聞き出そうとせず、出てきた分だけメモする。

### 4. 無料15分ヒアリング

相手が困りごとを話してくれたタイミングで、その場で提案する。

```
それ、一回ちゃんと整理したら結構楽になると思います。
15分だけ、今のやり方詳しく聞かせてもらえたら、
何か力になれるか考えてみますよ。無理にお願いすることはないので。
```

- 日程調整は新しいフォームを作らずLINE・DMで直接でいい（最初の1件のためだけに予約フォームを作らない）。
- ヒアリングの中身は `account-ledger/hearing_sheet.txt` の聞き方をそのまま流用：
  1. 今、業務でよく使っているツール・やり方は何か
  2. どこに一番時間や気持ちを取られているか
  3. 過去に困った・不安になった経験はあるか
- ヒアリングは「診断」ではなく「相手の話を聞く時間」として進める。こちらの提案は最後にまとめて話す。

### 5. ¥33,000を提案するタイミング

ヒアリングの**最後**、相手が一通り話し終えて「こんな感じです」と言ったその直後。間を置かない。日を空けて連絡し直すと熱が冷める。

タイミングの目印：
- 相手が「地味に大変で」「なんとかしたいとは思ってて」と言った瞬間
- 同じ作業を繰り返している、または情報が複数箇所に散らばっていることが分かった瞬間

ここで初めて「実は」と提案に入る。売り込みではなく、聞いた内容への"返答"として出す。

### 6. 提案内容

フォームの機能説明はしない。**聞いた困りごとをそのまま要約して返す**ことが提案の8割。

```
今日聞いた感じだと、
・予約がLINEとDMに分かれてて確認が大変
・お客さんの情報を都度メモしてて漏れそうで不安
というあたりが一番の負担そうですね。

これ、Tallyで予約フォームを1つ作って、Googleカレンダーとスプレッドシートに
自動で反映されるようにすれば、今の確認作業はほぼなくなると思います。
（必要ならNotionで顧客情報もまとめて見られるようにできます）

費用は¥33,000です。今回、最初のお客様なのでモニター価格として¥16,500で
お受けしようと思っているんですが、どうですか？
納期は着手から3営業日くらいです。
```

- 価格は「今回だけ」の理由（最初のお客様だから）を添えることで安売り感を消す。
- 即答を求めない。「少し考えてみます」と言われたら、「もちろんです、急かすつもりはないので」で終える。ダッシュボードの提案書テンプレートタブに同じ内容を入れて、コピペで送れる形にしておく。

### 7. 断られた場合に残す学習データ

新しいシートは作らない。ダッシュボードの「案件・顧客管理」タブで、ステータスを**見送り**に変更し、メモ欄に次の3つだけ短く残す。

1. 断られた理由（価格／タイミングが悪い／自分でやってみたい／信頼しきれなかった、など。相手の言葉をそのまま書く）
2. どの段階で温度が下がったか（ヒアリング中／提案直後／提案後の沈黙）
3. 次に同じ場面が来たら変えること（一言でいい）

この3行だけ。分析はしない。3〜5人分たまったら、パターンが1つでも見えれば十分。

## 使うもの（すべて既存。新しく作らない）

- `account-ledger/hearing_sheet.txt` → ヒアリングの聞き方の台本
- [ダッシュボード](https://claude.ai/code/artifact/9b85521f-5acd-44bd-b81f-279724cb3535) の「案件・顧客管理」タブ → 声をかけた3〜5人の記録と、断られた理由のメモ
- 同ダッシュボードの「提案書テンプレート」タブ → ¥33,000（モニター¥16,500）の提案文をコピペで作る
- 同ダッシュボードの「売上記録」タブ → 成約したら記録するだけ

「30日チェックリスト」タブと週次KPIの数値目標は、今は使わない。件数を追う段階ではないため。
