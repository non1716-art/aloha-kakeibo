================================================================
  Googleスプレッドシート 完全セットアップ手順
  アカウント・権限管理台帳（初心者向け）
================================================================

【所要時間の目安】
  インポート：5分
  書式設定：15〜20分
  フィルター設定：5分
  合計：約30分

================================================================
STEP 1｜CSVをGoogleスプレッドシートに取り込む
================================================================

1. Googleドライブ（drive.google.com）を開く

2. 画面左上の「＋新規」ボタンをクリック

3. 「ファイルのアップロード」を選ぶ

4. ダウンロードした「account_ledger_v2.csv」を選択してアップロード

5. アップロードが完了したら、ファイルを右クリック
   →「アプリで開く」→「Googleスプレッドシート」を選ぶ

6. 開いたら、メニュー「ファイル」→「Googleスプレッドシートとして保存」をクリック
   ※ これで編集できる状態になります

================================================================
STEP 2｜見やすくする基本設定（5分）
================================================================

【ヘッダー行を固定する】

1. 1行目（No.・カテゴリ…と書いてある行）をクリック
2. メニュー「表示」→「固定」→「1行」をクリック
   → スクロールしても項目名が常に見えるようになります

【ヘッダー行を目立たせる】

1. 1行目を選択した状態で
2. 背景色ボタン（バケツのアイコン）をクリック
3. 濃いめのグレーや紺色を選ぶ
4. 文字色を白に変更する
5. 太字ボタン（B）をクリック

【列幅を自動調整する】

1. 列全体を選択（Aの左の四角をクリックで全選択）
2. 列の境界線をダブルクリック
   → 内容に合わせて自動で幅が調整されます

================================================================
STEP 3｜危険度の色分け設定（条件付き書式）
================================================================

【危険度「高」→赤、「中」→黄、「低」→緑 に自動色付け】

■ 準備：危険度が入っている列を確認する
  → O列（15列目）が「危険度」です

【赤の設定（危険度：高）】

1. O列全体をクリックして選択
2. メニュー「書式」→「条件付き書式」を選ぶ
3. 画面右に設定パネルが開く
4. 「セルの書式設定の条件」で「次を含むテキスト」を選択
5. 下のテキストボックスに「高」と入力
6. 「書式設定のスタイル」で背景色を赤（#EA4335 または濃い赤）に設定
7. 文字色を白にする
8. 「完了」をクリック

【黄の設定（危険度：中）】

1. O列が選択された状態で、右のパネルの「＋ 別のルールを追加」をクリック
2. 「次を含むテキスト」を選択
3. 「中」と入力
4. 背景色を黄（#FBBC04 またはオレンジ系）に設定
5. 「完了」をクリック

【緑の設定（危険度：低）】

1. 同様に「＋ 別のルールを追加」をクリック
2. 「次を含むテキスト」で「低」と入力
3. 背景色を緑（#34A853 または薄い緑）に設定
4. 「完了」をクリック

→ これで危険度の列が自動で赤・黄・緑に色付けされます！

================================================================
STEP 4｜2段階認証「無し」を目立たせる
================================================================

【2段階認証が「無し」のセルを赤くする】

1. F列（2段階認証の列）を全選択
2. メニュー「書式」→「条件付き書式」
3. 「次を含むテキスト」→「無し」と入力
4. 背景色：薄い赤（#FCE8E6）、文字色：赤（#C62828）に設定
5. 「完了」をクリック

→ 2FA未設定のサービスが一目で分かります

================================================================
STEP 5｜パスワード保管場所の非標準管理を目立たせる
================================================================

【メモアプリ・紙など非推奨の保管場所を赤くする】

1. K列（パスワード保管場所）を全選択
2. メニュー「書式」→「条件付き書式」
3. 「次を含むテキスト」→「メモアプリ」と入力
4. 背景色：薄い赤（#FCE8E6）、文字色：赤（#C62828）に設定
5. 「完了」をクリック
6. 同様に「＋ 別のルールを追加」で「紙」「Excel」「メール」なども追加

→ パスワードマネージャー未使用の箇所が一目で分かります

================================================================
STEP 6｜カテゴリ・管理者でフィルターを設定する
================================================================

【フィルター機能を追加する】

1. 1行目のどこかをクリック
2. メニュー「データ」→「フィルターを作成」をクリック
   → 各列のヘッダーに▽ボタンが表示される

【使い方の例】

  ・「カテゴリ」の▽ → 「インフラ」だけ表示
  ・「管理者」の▽  → 特定の担当者のサービスだけ表示
  ・「危険度」の▽  → 「高」だけ絞り込んで優先確認
  ・「2段階認証」の▽ → 「無し」だけ絞り込んで対応漏れチェック

================================================================
STEP 7｜最終確認日が古いものを見つける書式
================================================================

【90日以上確認していないセルを色付けする】

1. N列（最終確認日）を全選択
2. 「書式」→「条件付き書式」
3. 「カスタム数式」を選択
4. 以下の式を入力：
   =AND(N2<>"",N2<TODAY()-90)
5. 背景色をオレンジに設定
6. 「完了」をクリック

→ 90日以上確認していないサービスが自動でオレンジ色になります

================================================================
STEP 8｜シートの整理（カテゴリ別タブ）
================================================================

【応用：カテゴリごとにシートを分ける】

1. 画面下の「＋」をクリックしてシートを追加
2. シート名を「インフラ」「経理・会計」「SNS」などにする
3. 元のシートでカテゴリでフィルターして、該当行をコピー
4. 各シートに貼り付ける

→ カテゴリ別に担当者と共有する場合に便利です

================================================================
STEP 9｜定期確認のリマインダー設定（Googleカレンダー連携）
================================================================

【月1回の台帳確認リマインダーを設定する】

1. Googleカレンダーを開く
2. 「＋ 作成」→「イベント」
3. タイトル：「アカウント台帳の月次確認」
4. 日時：毎月1日（もしくは月末）
5. 「繰り返し」→「毎月」に設定
6. 通知：前日の午前9時などにメール通知
7. 説明欄にスプレッドシートのURLを貼り付ける

→ これで確認漏れが防げます

================================================================
STEP 10｜お客様と共有する方法
================================================================

【スプレッドシートを特定の人だけに共有する】

1. 右上の「共有」ボタンをクリック
2. 共有したい相手のGmailアドレスを入力
3. 権限を選ぶ：
   ・「閲覧者」→ 見るだけ（お客様や税理士向け）
   ・「編集者」→ 編集もできる（担当スタッフ向け）
4. 「送信」をクリック

【リンクで共有する場合】

1. 「共有」→「リンクをコピー」
2. アクセス権限：「リンクを知っている全員（閲覧者）」に設定
3. リンクをメール・チャットで送る

※ 機密情報なので「リンクを知っている全員」は慎重に使用すること
